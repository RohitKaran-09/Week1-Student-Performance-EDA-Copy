This report documents my Week 1 project on Data Acquisition, Cleaning, and Exploratory Data Analysis (EDA) using the Student Performance dataset from the UCI Machine Learning Repository. The project focuses on the Mathematics course file from the public dataset and uses Python libraries including Pandas, NumPy, Matplotlib, Seaborn, and python-docx. The Python script acquires the official UCI archive, extracts the data, and records the source so the analysis can be reproduced. It does not silently replace the official data with synthetic demonstration records.

The workflow begins by inspecting the data dimensions, types, missing values, and duplicate rows. Cleaning methods include trimming whitespace in text fields, safely converting numeric columns, removing exact duplicate records, validating plausible ranges for grades and other numeric fields, and handling invalid or missing values with documented rules. Numeric missing values, if any, are imputed using column medians; categorical missing values are filled using the mode or an Unknown label. A cleaning audit and summary-statistics file are exported to make the process transparent.

The exploratory analysis contains four visualizations: a histogram of final grades, a bar chart comparing average final grades across weekly study-time categories, a scatter plot of absences against final grades, and a correlation heatmap for selected numeric variables. The report includes computed grade statistics, a descriptive pass-rate indicator, study-time group comparisons, and correlations with absences and earlier period grades. It also discusses important limitations: observational associations do not prove causation, and using earlier grades to predict final grades can cause target leakage depending on the intended prediction time.

The repository includes the source code, requirements, README, this submission description, the official data file, generated charts, cleaned data, audit tables, metrics, and a DOCX report. A GitHub Actions workflow runs the analysis using the official UCI data and commits the generated report and results back to the repository. Findings should be interpreted in the context of the source population: students from two Portuguese secondary schools.
